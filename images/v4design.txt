2.1 Record 格式（每个 implementation-target class 必须包含全部 11 块；
    缺任何一块 = schema violation）：

    R1  Identity        {EventClassID / EventFamily / SpecificityCeiling /
                         AmbiguityClass / Views / Status}
    R2  StructuralPremises[]   每条带来源 tag（2.2）
    R3  V4Supplementary[]      每条含 derivationID / version / input /
                         outputType / literatureProvenance / T1-T4 verdict
    R4  SchoolPluginDeps[]     （可空）
    R5  RequiredConditionSet   显式合取，逐 conjunct 编号
    R6  ExclusionSignals[]     确定性排除（触发 → conflicted）
    R7  SupportingSignals[]    非必要证据（影响 breadth/corroboration，
                         不影响身份）
    R8  Provenance             {literatureBasis / rationale / applicability /
                         knownAmbiguity / counterInterpretation}
                         —— 任一子项无法给出时写 UNVERIFIED — DO NOT INFER，
                         禁止为完成表格补规则
    R9  Temporal               {YearReachability / MonthReachability /
                         DayRole / ExactDateDiscriminator}
    R10 EvidenceStateTriggers  {insufficient / supported / conflicted /
                         unresolved} 的机械触发条件
    R11 Fixtures                {F-P / F-N / F-C / F-A / F-PO / F-D} 规格 ID
                         （仅 DESIGN SPEC，本轮不执行，§18）

2.3 全局不变量（对全部 40 class 成立；§19 Second Pass 逐行核验）：

    INV-1  DayRole = corroboration-only（全局）。日层同族结构证据永远只能
           corroborate，不得单独升级任何 timing resolution（FX-G 全局化）。
    INV-2  ExactDateDiscriminator = NONE（全部 class）⇒ EXACT_DATE 全局
           不可达（reserved state；Hardened §10.3）。任何 class 的 Timing
           语义不得写 EXACT_DATE reachable。
    INV-3  AmbiguityClass C ⇒ SpecificityCeiling ≤ L2；C + L3 = INVALID

    INV-4  每个 RequiredConditionSet 满足：conjuncts ≥ 2，且
           （≥2 个不同 source families ∨ conjuncts 来自 ≥2 个 AGG-3 独立
           域）。单 premise 不得满足任何 RequiredConditionSet（one signal
           → one event 禁令的 registry 化）。
    INV-5  零 Double / score / weight / probability / ranking / 序数 ladder。
           唯一许可的数值使用 = 基数→枚举映射（如「≥2 个独立交互并见」
           → breadth 枚举；Hardened §11.4）。
    INV-6  Plugin 证据只能 ADD。plugin → candidate creation、plugin 修改
           identity / ambiguity / timing / Event Class、plugin 删除 core
           evidence = CONTRACT VIOLATION（Hardened §15.2 X-1~X-8）。
           plugin-off 存在性由 coreEvidenceState 机械回答（Hardened §15.4）。
    INV-7  历史防火墙（§20）：Owen/Jassica 数据不出现在任何 R1-R11 字段。
    INV-8  本轮 Status 允许降级、禁止升级；升级唯一路径 = 未来经授权的
           discriminator 程序（Hardened §14.3：禁止历史倒推）。

2.4 词汇纪律：
    - AMBIGUOUS-C class 仍可产出 L2 candidate，但恒带 C 标注，永不进入 L3。
    - NOT-EXPRESSIBLE class 不建 generator；仅登记负例 fixture（§18）。
    - DEFERRED class 不建终版 RequiredConditionSet；草案与 blocker 登记。
    - Health/Safety 家族全部输出词汇 = 「health 域结构信号」级，禁止任何

§15 EVIDENCE STATE AUDIT（全局机械触发定义）
================================================================================

15.1 四态触发条件（对全部 class 统一；class 特有附加触发以 R10 登记）：
    - insufficient：R5 任一 conjunct 缺失。含 core-only 场景下 [School:]
      conjunct 恒缺 → insufficient-by-construction（§16.4）。
    - supported：R5 全部 conjunct 满足。由 INV-4（≥2 source families ∨
      ≥2 AGG-3 独立域），supported 状态下 Corroboration ≥ multi-source
      自动成立，无须另行声明。
    - conflicted：R6 任一 ExclusionSignals 确定性触发（合绊 excludedOnly
      全覆盖 / 方向相悖 / 官杀克身等）。conflicted 覆盖 supported——
      同一评估周期内 R6 触发时输出 conflicted，不输出 supported。
    - unresolved：跨 class 并发身份歧义（§17 并发组内 ≥2 class 同时满足
      各自 R5）或 class 内 identity UNRESOLVED（如 W-1 views）。候选存在
      但身份歧义——不排除、不删除、不择一。

15.2 优先级（同一候选、同一评估周期）：
    conflicted > unresolved > supported。
    - conflicted 与 supported 同现 → 输出 conflicted。
    - unresolved 与 supported 同现 → 输出 supported + unresolved flag
      （§17 并发组双登记均保留）。
    - conflicted 与 unresolved 同现 → 该 class 侧输出 conflicted；并发组
      另一侧不受影响。

15.3 Breadth / Corroboration 映射（三正交字段之二；Hardened §11）：
    - EvidenceBreadth：narrow / moderate / broad——由 premise 家族覆盖与
      N2 档位机械决定（基数→枚举映射，INV-5 唯一许可数值使用）。基准：
      R5 最小集满足 = narrow；R7 supporting 命中 ≥2 项或 N2 ≥ high →
      moderate；multi-temporal 与上述任一并见 → broad。
    - Corroboration：single-source / multi-source / multi-temporal——
      multi-temporal 仅当 Y 与 M 同族证据并存（Day 永不计入升级，INV-1）。
    - 禁止跨维 ordinal ladder（「corroborated > broad」类排序不存在）；
      禁止 confidence score / weight / probability / Double / ranking
      （INV-5）。

15.4 状态可逆性与无状态性：
    - 全部四态由当前证据集合机械重算；不累积、不衰减、无历史状态机。
    - 状态不写入任何 V3 输出（Layer A/B/C 分离）；EventSnapshot 记录
      状态与触发 conjunct 清单（可追溯枚举，零数值）。
