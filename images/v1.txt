§1 SCOPE / OBJECTIVE
════════════════════════════════════════════════════════════════════════════

本报告建立「同一个真实世界事件 → Owen 独立 V3 observation + Jassica 独立
V3 observation」的双命盘历史证据结构。

核心原则：
  1. 双计数禁令（ABSOLUTE NO DOUBLE-COUNTING）：
     每一行证据 = 1 个现实事件 + 2 个独立 chart observations（Owen 一侧、
     Jassica 一侧）。任一侧的 observation 不得覆盖、改写或合并另一侧。
  2. Domain-agnostic（不预设 domain）：
     结婚 ⇏ relationship；买房 ⇏ wealth；生孩子 ⇏ children；
     搬家 ⇏ travel；公司收入新高 ⇏ wealth/career。
     V3 输出是什么，登记什么。观察域归属只描述、不解释、不修正。
  3. Observed Association 仅描述性：
     本报告只描述双侧 raw 输出的机器事实。禁止书写「命中了 / 预测成功 /
     算法准确 / 验证通过 / 倒置矛盾」等任何 accuracy 判断。
  4. 日期精度权威（DATE PRECISION AUTHORITATIVE）：
     YEAR_ONLY 只比年度层；MONTH_ONLY 比 month probe + resolved 年度
     snapshot；EXACT_DATE 可比 day + month + annual。立春边界
     （resolvedAnnualYear）以管线输出为准，不与 calendar-year 混淆。
     精度冲突只登记 discrepancy，不自行修正。
  5. 无补写（NO BACKFILL）：
     任何一侧不存在的输出，明确写 NONE / NOT PROBED。不重跑 V3，
     不补 probe，不推测缺失内容。
  6. 不进 Historical Validation / Calibration：
     本报告只建立证据结构，不用于任何 tuning / calibration / threshold /
     semantic rule 输入。
