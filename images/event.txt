§0 EXECUTIVE SUMMARY
================================================================================

核心结论一句话：Frozen V3 是一座「结构状态观测站」（structural-state
observatory），不是「人生事件观测站」（life-event observatory）。它对 15 类
干支结构（冲合刑害破、天克地冲、反吟伏吟、伤官见官等）在 Year/Month/Day 三层
的激活、方向、形态、量级具有完整、独立、可追溯的观察能力；但它对任何具体
人生事件（结婚/生育/买房/融资/丧亲/企业成败……）均不存在显式 event detector
或 event semantic。事件语义在整条链上任何一层都不存在——因此不存在
「信号产生后被丢失」的事件级问题；存在的是「事件语义从未进入架构」的问题。

三问回答：

Q1（V3 已经能表达什么）：
  a) 15 类 InteractionKind 的结构检测（PipelineV2Types.swift L336-374），
     经 V2 detector 只读复用进入 V3（V3CoreTypes.swift L152-161）。
  b) 十神→候选域 5 组映射 + 宫位→候选域 4 槽位映射（DomainMapper.swift
     L130-166）。这是 STRUCTURAL DOMAIN ATTRIBUTION，不是 event detection。
  c) 域级 N1（activation/direction/confidenceShape，九域恒产出、域间零桥接，
     V3N1Semantics.swift L41/L77/L229）与域级 N2 五档量级
     （quiet/low/moderate/high/extreme；liuHe/stemWuHe excluded）。
  d) Year/Month/Day 三层独立评估（Unified Core，V3CoreTypes.swift L26-35；
     A1 锚规则 V3AnchorAndFamilyRules.swift L25-31）。
  e) 年层确定性派生事实 R-1~R-4 + R-6（YearV3Snapshot.swift L3-54），
     快照完整保留 year evaluation + 12×month evaluation。
  f) 三层 UI 呈现（Today/Monthly/Annual Presentation Builder）。

Q2（理论上应能表达、但当前架构没有表达什么）：
  a) 全部事件级语义：marriage / wedding / divorce / childbirth / property /
     financing / bereavement / business lifecycle / relocation / surgery 等
     ——Detector 层 ABSENT（§4）。
  b) 神煞族输入：红鸾/天喜/桃花/驿马/空亡/纳音——V3 输入层 ABSENT
     （§3；EventPriority P6 通道在 mapEvent L790 guard 返回空）。
  c) 三合/半合：lattice 登记为 inertNoV2Kind——V2 无对应 InteractionKind
     （V3CoreTypes.swift L133-137）。
  d) travel 域的十神通道：travel 仅由 natalYear 槽位承载
     （DomainMapper.swift L163），无任何十神映射到 travel。
  e) quiet(P) 域的合绊信息在 N2 量级上按冻结语义被排除
     （liuHe/stemWuHe excluded kind）——量级视角的 by-design 表达空缺。

Q3（已产生 structural signal、但在哪一层未被继续观察/展示）：
  a) R-6 temporalFacts 中 peakLevel=moderate 的事实存在于 Snapshot
     （存在门 peakLevel != .quiet），但展示门
     temporalPresentationLevels={high,extreme}（YearV3Contract L71）使其
     不进入 M5 WHEN 呈现——GAP-G（数据保留、呈现过滤）。
  b) R-3 focus 超 3 域 / R-4 watch 超 2 域时 overflow 保留为事实但不出现在
     主呈现（YearV3Snapshot.swift L29-34, L141-145）——GAP-G（容量过滤，
     非数据丢失）。
  c) DomainMapper 归因成功但落域为 quiet 的结构信号（尤其合绊类）：
     N2 量级不缩放 excluded kind，域状态以 quiet(P) 呈现——观察者为
     「无信号」；族信息仍可从 N1 family count 观察（quiet(A) 与 quiet(P)
     区分，§7）。
  d) 未发现「V3Core 产生 signal → Snapshot 丢弃」的链路：Snapshot
     逐字保留 year + 12×month evaluations（§9）。

    excluded: liuHe / stemWuHe（合绊类不入量级）
7.2 双轨 quiet 区分（任务书 §9 明令）：
  quiet(A) = coverage ABSENT——该域零 PRIMARY（无任何族触发）。
  quiet(P) = coverage PRESENT——有 PRIMARY，但全部为 excluded kind
  （仅合绊类）；量级按冻结语义不缩放 → 显示 quiet。
  二者是不同架构状态：quiet(A) = 「无结构进入该域」；quiet(P) = 「结构
  进入但为合绊类、量级通道不表达」。混同将丢失合绊可见性。
  代码证据：excluded 集合见 N2 冻结规则（V3RuleTable 结构接口 +
  provisionalKindTier 分级）；Snapshot 侧 quietDomains 定义
  （YearV3Snapshot.swift L150「N2 quiet 域（固定域序; 含 excluded-only
  resolving 域）」——excluded-only 域被显式保留于 quietDomains，架构上
  未丢弃覆盖信息）。
7.3 coverage semantics：
  - excluded interaction kinds：liuHe/stemWuHe 永不入量级（7.1）；
  - interaction 计数不进 magnitude（N2 无 count 通道，冻结）；
  - 九域恒产出（AGG-3）→ N2 对九域全覆盖，无缺域。
7.4 逐事件 N2 可观察性：
  同 §6.5 逻辑：premises 落入 15 kind 且为非 excluded kind → 可观察量级；
  仅合绊类触发 → quiet(P)；premises 为神煞/三合/藏干透出 → 无 N2 通道。

8.1 锚层规则（V3AnchorAndFamilyRules.swift L25-31, A1 anchorLayer）：

8.2 年层（YearV3Snapshot.swift Builder L472-511）：
  - anchor：年中锚点 6 月 15 日（L472 注释「与大运/流年口径一致」）。
  - 年层语义源：`V3Core.evaluate(natal:daYun:date:anchorDate, viewKind:.year)`
    （L474-484）——唯一 Year semantic source（L9 冻结注释）。

    枚举/计数比较，L19「零 Double/Float 语义计算」）；不存在跨层语义聚合

8.3 月层：
  - 12× 月锚（每月 15 日，comps.day=15）独立调用

    而 m7 children R-2 事件 extreme——年/月独立评估的直接证据；

8.4 日层：
  - 独立调用 V3Core.evaluate(viewKind:.day)（unified core；TodayV3 链）。
  - 日层不继承月层/年层 signal（同 8.3 逻辑，独立入参）。
  - Day→Month / Day→Year 回流：不存在。R-6 方向为 month→year 单向
    （L43-53「叶节点: 不被任何其他 R-pass 消费, 无 feedback path」）；
    无任何 day→month / day→year pass。

  R-2: annualActivated ⇔ 年 N2 != quiet；eventMonth ⇔ 月度域 N2∈{high,extreme}；
       MainLineKind: annualActivatedCount≥1→multiFocus / eventMonthCount≥1→
       eventDriven / else steady。

       （排序 N2 desc → shape → 固定域序；overflow 保留为确定性事实 L141-142）。
  R-4: WatchPool = (Candidate−Displayed) ∧ UNFAVORABLE；top2；无 N2 floor；
       MIXED never。
  R-1: 窗口 = 月度 N2∈{moderate,high,extreme} ∧ direction∈{F,U} ∧ 同域同向

       存在门 peakLevel != .quiet；三存储字段（L107-116）；叶节点无反馈。
9.3 suppress / collapse / aggregate / lose / preserve 判定表：
  行为                       | 存在? | 证据/说明
  ---------------------------+-------+--------------------------------------
  suppress 原始评估          | NO    | yearEvaluation/monthEvaluations 逐字
  collapse 到单一数值        | NO    | Snapshot 全字段零 Double（L19）
  aggregate 跨层语义         | NO    | 年 N2 独立；R-pass 全为序数/枚举/计数
  lose 域覆盖                | NO    | 九域恒产出；quietDomains 含 excluded-
                             |       | only 域（L150）
  preserve semantic identity | YES   | 域/direction/shape/intensity/月序全部

                             |       | 数据在 Snapshot 内保留，仅 UI 不展示
                             |       | （overflowDomains L141-142 为证）
9.4 结论：未发现「V3Core 有 signal 但 Snapshot 丢弃」；发现两处「Snapshot

  计数仍可观察。
